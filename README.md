# Discord Music Bot 🎵

Bot ديسكورد للأغاني مبني بـ Python.

## الأوامر

| الأمر | الوصف |
|-------|-------|
| `!play [اسم/رابط]` | شغّل أغنية |
| `!skip` | تخطى الأغنية |
| `!pause` / `!resume` | وقّف / استكمل |
| `!stop` | وقّف واطلع |
| `!volume [0-200]` | غيّر الصوت |
| `!loop [none/song/queue]` | Loop |
| `!queue` | قائمة الانتظار |
| `!nowplaying` | الأغنية الحالية |
| `!shuffle` | خلط القائمة |
| `!lyrics` | كلمات الأغنية |

## Environment Variables

```
DISCORD_TOKEN=your_token_here
GENIUS_TOKEN=your_genius_token_here  (اختياري)
```
